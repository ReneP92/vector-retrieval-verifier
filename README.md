# RAG Retrieval Evaluator

A provider-neutral framework for benchmarking BM25, dense, hybrid, and reranked
retrieval against labeled production data.

See [PROJECT_PLAN.md](PROJECT_PLAN.md) for the architecture and implementation
plan.

The [FiQA retrieval workbench](demo/README.md) demonstrates the production-shaped
retrieval path that future offline evaluations will measure.
